# BTC 초단타 Android

[휴대폰에서 최신 APK 설치](https://github.com/canfisher/btc-scalper-android/releases/latest/download/btc-scalper.apk)

처음 한 번 휴대폰 브라우저로 위 링크를 열고 기존 앱 위에 업데이트 설치하세요. 앱 삭제·데이터 초기화는 하지 마세요.

v1.09부터 앱 화면을 열면 새 버전을 확인하며, 화면이 켜진 동안 6시간 간격으로 다시 확인합니다. 새 APK는 자동으로 내려받고, 업데이트 버튼으로 설치를 승인합니다. 처음 한 번 BTC 초단타의 ‘이 출처 허용’ 설정이 필요합니다.

매매 실행 중 또는 미확인 주문이 있으면 설치가 차단됩니다. 매매 중지 후 설치하고, 설치가 끝나면 직접 다시 시작하세요. 키와 장부는 보존됩니다. PC 장부 이전은 앱의 ‘PC 장부 가져오기’를 사용합니다.

이 저장소에는 서명된 APK와 업데이트 정보만 배포합니다. 사용자 API 키·거래 장부·앱 서명 비밀키는 포함하지 않습니다. 수익성은 검증되지 않았습니다.
